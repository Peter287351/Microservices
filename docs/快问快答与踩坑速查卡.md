# 一、快问快答（11 模块 × 3 题）

## 模块 00 · 脚手架
| 快问 | 快答 |
|------|------|
| dependencyManagement 和 dependencies 区别？ | **价目表 vs 真引用**：前者只锁版本不引入；子模块免写版本号；版本集中防冲突 |
| 为什么有自增 id 还要 order_no？ | id=物理主键（聚簇索引友好、不外泄）；order_no=业务单号（可读、可换雪花算法） |
| 金额为什么 decimal 不用 double？ | 二进制浮点算不清 0.1；钱必须精确 → BigDecimal |

## 模块 01 · Nacos 注册中心
| 快问 | 快答 |
|------|------|
| 注册中心挂了还能调吗？ | **能**。实例列表缓存在本地；客户端自动重连+重放注册（redo）；新实例注册会失败 |
| 实例死了怎么被发现？ | 心跳：5s 一次，15s 不健康，30s 剔除（kill -9 靠它兜底） |
| 调用方报错能反馈给 Nacos 剔除吗？ | 不能——网络抖动会误杀；健康判定归实例心跳（职责分离），调用方靠重试/熔断 |

## 模块 02 · Nacos Config
| 快问 | 快答 |
|------|------|
| optional: 前缀去掉会怎样？ | Nacos 没这份配置就**拒绝启动**（fail-fast）；核心配置不加、装饰配置加 |
| 改配置不生效 top3 原因？ | ①没加 @RefreshScope ②Data ID/Group 错（.yml≠.yaml）③YAML 格式错 |
| @RefreshScope 原理？ | 变更事件 → 销毁 Bean → 下次请求用新配置重建（@Value 只在创建时注入一次） |
| 密码放哪？ | Nacos（动态轮换+不进 git）；引导配置留本地；**不绝对安全**→鉴权+网络隔离 |

## 模块 03 · OpenFeign
| 快问 | 快答 |
|------|------|
| 接口没实现类怎么发请求？ | **JDK 动态代理**（$Proxy134）：读注解拼 HTTP → 查 Nacos → 发送 → 反序列化 |
| 下游挂了是什么失败？ | **快速失败**（LB 发现空列表直接 503）；现象叫级联失败；解法=多实例/熔断/异步 |
| 为什么新建 UserDTO？ | **防腐层**：服务间只耦合 HTTP+JSON 契约；共享实体=编译期强耦合 |

## 模块 04 · LoadBalancer
| 快问 | 快答 |
|------|------|
| 客户端 LB vs 服务端 LB（Nginx）？ | 进程内挑实例+列表来自注册中心 vs 中间人+手工配置；内部调用选前者（少一跳、自动感知扩缩容） |
| 停实例后多久感知？ | ~30 秒脏窗口（心跳剔除+推送/缓存刷新），靠重试兜底 |
| 想让强机器多接单？ | 加权轮询（需权重值+健康状态）；Nacos 权重+NacosLoadBalancer |

## 模块 05 · Gateway
| 快问 | 快答 |
|------|------|
| StripPrefix=1 什么意思？ | 剥掉路径第 1 段：/api/users/1 → /users/1；路径本身无前缀则配 0/不配 |
| lb:// 是什么？ | 目标是**服务名**——查 Nacos+负载均衡（复用模块 01+04） |
| 网关为什么不能依赖 common？ | common 传递 spring-web（MVC），Gateway 是 WebFlux，共存即启动报错 |

## 模块 06 · Sentinel
| 快问 | 快答 |
|------|------|
| QPS 阈值 vs 并发线程数阈值？ | 每秒放行多少 vs 同时处理多少；前者保入口总量，后者保慢下游不堆积线程 |
| 熔断三态？ | 闭合→（慢/错超阈值）→打开（快速失败走 fallback）→半开（试探）→闭合/继续打开 |
| 规则为什么重启就丢？ | 存服务内存；生产推 Nacos 持久化（配置中心复用） |
| 控制台看不到服务？ | 懒加载——先请求一次服务才现形 |

## 模块 07 · Zipkin 链路追踪
| 快问 | 快答 |
|------|------|
| Trace 和 Span？ | Trace=一次请求全程（唯一 ID）；Span=其中一段耗时区间，父子成树 |
| 链路怎么跨服务串起来？ | TraceId 随 **HTTP Header**（b3/traceparent）传播，每跳读 Header 延续 |
| 生产采样率多少？为什么？ | 0.1（10%）省成本；只追失败→尾采样（error/慢调用 100% 保留） |
| Feign 调用链路断了？ | 缺 **feign-micrometer**（E07-1）——每个客户端库要单独埋点 |

## 模块 08 · Stream + RocketMQ
| 快问 | 快答 |
|------|------|
| Feign vs MQ 怎么选？ | 前置依赖（要结果才继续）→ Feign 同步；后置动作（不等结果）→ MQ 异步 |
| 消息会在哪丢？ | 生产者（同步确认+重试）/ Broker（SYNC 刷盘+副本）/ 消费者（手动 ACK+重投） |
| 重复消费怎么办？ | 至少一次投递必然重复 → 消费端**幂等**（orderNo 防重）；至少一次+幂等=恰好一次 |
| 同组 vs 不同组消费者？ | 同组**分摊**（负载均衡），不同组**各收全量**（广播） |

## 模块 09 · Seata AT
| 快问 | 快答 |
|------|------|
| AT 两阶段？ | 一阶段：前镜像→SQL→后镜像→undo_log→**本地提交**→注册分支；二阶段：提交删日志 / 回滚按镜像反向补偿 |
| TC/TM/RM 各是谁？ | TC=seata-server 协调；TM=@GlobalTransactional 发起方（order）；RM=连库服务的数据源代理 |
| XID 怎么传播？ | Feign 拦截器写 HTTP Header（TX_XID）；断了=回滚一半 |
| 秒杀热点行为什么卡？ | 全局锁按行串行 → 换 TCC / Redis 预扣+MQ 最终一致 / 库存分桶 |
| undo_log 是什么？ | 回滚镜像表（前后快照），每个参与库都要建；回滚按前镜像生成反向 SQL |

## 模块 10 · Security + JWT
| 快问 | 快答 |
|------|------|
| 认证 vs 授权？ | 你是谁（auth 登录验证密码）vs 你能干什么（网关验票+权限扩展） |
| JWT 三段？ | Header(算法).Payload(声明，可解码**不可篡改**).Signature(HS256 签名)；验签名+验 exp 即可信 |
| 为什么不存 session？ | 状态在令牌里，任何实例拿密钥即可验——天然适配多实例/多服务 |
| token 泄漏怎么办？ | 短时效 + HTTPS + 不放敏感信息 + refresh token/黑名单；**无法作废**是天生弱点 |

# 二、踩坑速查表（一行一条，详见错误知识库对应编号）

| 编号 | 症状（一眼认出） | 一句话根因 | 一句话解法 |
|------|----------------|-----------|-----------|
| E00-1 | 容器起不来 `port already in use` | 宿主机端口被占 | 换映射端口 `宿主机:容器` |
| E00-2 | jar 报"没有主清单属性" | 自定义父工程没配 repackage | 显式声明 repackage goal |
| E00-3 | 接口 500：parameter name not available | 编译丢参数名（Spring 6.1 不再兜底） | `-parameters` 编译参数 |
| E00-4 | 中文 JSON 报 `Invalid UTF-8 0xbb` | Windows 控制台 GBK 发中文 | UTF-8 文件 + `--data-binary @file` |
| E00-5 | 缺参数返回 500 | 异常落进兜底处理器 | 精确 @ExceptionHandler → 400 |
| E00-6 | `Communications link failure` | 容器没起/端口错/密码错 | 三查：healthy→3307→root123 |
| E00-7 | `index.lock: File exists` | 上次 git 操作残留锁 | `rm -f .git/index.lock` |
| E00-8 | docker exec 查中文 `????` | 客户端 latin1 显示乱（数据没坏） | 加 `--default-character-set=utf8mb4` |
| E00-9 | 类型不匹配返回 500 | 落入兜底异常处理器 | 专属 handler → 400 |
| E01-1 | Nacos 控制台免登录 | standalone 默认未开鉴权 | 生产 `NACOS_AUTH_ENABLE=true`+隔离 |
| E03-1 | 启动报 `No Feign Client for loadBalancing` | SC2023 openfeign 不再传递 loadbalancer | 显式加 loadbalancer 依赖 |
| E07-1 | Zipkin 链路在 Feign 断裂（下游独立 TraceId） | 缺 feign-micrometer 埋点 | 加 feign-micrometer 依赖 |
| E08-1 | IDEA 报未解析依赖，CLI 却成功 | 双 Maven 配置（仓库/镜像不同步） | 复制 settings 到 ~/.m2 + 删 `.lastUpdated` |
| E08-2 | IDEA 编译大面积"找不到符号"（getter/setter） | Lombok 1.18.30 不支持 JDK23 | 升 1.18.36（BOM import 不吃属性覆盖，须直接声明条目） |
| E08-3 | 下单 429"太火爆"但没流量 | MQ 发送失败被 fallback 吞 | brokerIP1=宿主机可达 IP + MQ 失败不拖垮下单 |
| E08-3b | 修完 Broker 仍 `No route info` | Topic 没建（自动建失效） | `mqadmin updateTopic` 手动建 |
| E08-4 | MQ 控制台 8180 打不开 | 镜像默认监听 8082 | compose 里 `SERVER_PORT: "8080"` |
| E09 | 网关转发某路径 404 | 路由漏配/StripPrefix 算错 | 补路由+核对剥前缀段数 |
| E10-1 | 限流提示出现但没配限流 | Seata 包装业务异常，fallback 判不出 | 沿异常因果链解包再 instanceof |
| E10-2 | 启动报 `duplicate key spring` | YAML 顶层键重复 | 合并为单一 spring 块 |
| E10-3 | 启动报缺 ReactiveJwtDecoder | WebFlux 不自动装配 secret-key | 手动声明 NimbusReactiveJwtDecoder Bean |

# 三、三条万能排查口诀

1. **命令行能过、IDEA 报错** → 对比两套 Maven 配置（E08-1）→ 再对比 JDK 版本（E08-2）
2. **启动即挂** → 从最后一个 `Caused by` 往上读，根因在链尾
3. **中间件类怪问题** → 先 `docker ps` + `docker logs <容器>`，再查"地址所有客户端都可达吗"（E08-3）
